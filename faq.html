Docker

How to see inside container ?

docker run --entrypoint /bin/bash -it hbmclip/hbmclip

How to update hbmclip container ?


First, remove image and container 
docker image rm -f hbmclip/hbmclip

Run your container 
docker run -it hbmclip/hbmclip:latest --about

Using web server

You need mapping ports: 
                 docker run -it -v "$PWD:/mnt" -p 8082:8082 hbmclip/hbmclip:latest --mode filesystemweb
