About

hbmclip is a code interpreter developed for the Harbour programming language. Below are some of its main features:

hbmclip Features

  1. Built-in core libraries: The native Harbour libraries are integrated into the interpreter.
  2. Partial support for third-party libraries: Includes portions of the Grump and SuperLib libraries.
  3. Cross-platform compatibility: Available for Linux (Ubuntu) and Windows 10.
  4. Script integration: Easily integrates with bash, .bat, and PowerShell scripts.
  5. Supported graphical libraries: Compatible with the Clipper standard and the GTSTD, GTWVT, and GTCRT libraries.
  6. Virtual header file inclusion: Most .ch files are embedded virtually, eliminating the need for them to be present on the system.
  7. Internet access: Provided via the cURL library.
  8. Database support: Native access to SQLite, PostgreSQL, and MySQL databases.
