Hello World

Your code:

FUNCTION HelloWorld() LOCAL name := "Your name" ? "Hello, " + name RETURN NIL

Run as above:

hbmclip hello.prg

Remote code

hbmclip https://raw.githubusercontent.com/hbmclip/cookbook/refs/heads/main/exec/exec01.prg

Docker example

docker run -it -v "$PWD:/mnt" hbmclip/hbmclip:latest main.prg --workdir /mnt

Code from pipe

Example 1

echo "FUNCTION Main; OutStd(1 + 1)" | hbmclip --mode pipe

Example 2

cat yourfile.prg | hbmclip --mode pipe

Code inside html (or another file type)

Example 1

hbmclip --filename https://hbmclip.github.io/poem.html --tag-source "<poem>"
* Use --filename when extension is not .prg ** The parameter --tag-source inform tag name where code is included.
